# WAVE 10

A first person zombie wave survival game built in Unity.

## About

Survive ten waves of zombies in a dark arena. Each wave gets harder with more zombies and faster pathfinding enemies. Kill zombies for a chance to drop loot including health, damage boosts, and speed boosts. Make it through wave ten to win.

## Controls

- WASD to move
- Shift to sprint
- Mouse to look
- Left click to shoot (auto fire)
- R to reload
- Escape to pause

## Features

- 10 waves of escalating difficulty (more zombies and faster speed each wave)
- Auto fire MP7 rifle with magazine and reload system
- Three powerup types: health, damage boost, speed boost
- NavMesh AI zombies with attack animations and spatial audio
- Main menu, pause menu, game over screen, and win screen
- Atmospheric horror lighting with fog and the Cold Night skybox

## Built With

- Unity (Built in Render Pipeline)
- C# for all gameplay logic
- AI Navigation package for zombie pathfinding
- TextMeshPro for UI

1. Clone the repo
2. Open the `My project` folder in Unity
3. Open `Assets/Scenes/MainMenu.unity`
4. Press Play and click Start
